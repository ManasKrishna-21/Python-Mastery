# 🐍 Python Learning Journey

A simple, day-by-day repository for learning Python from the basics to real projects, using Jupyter notebooks with explanations, examples and practice questions.

## 📚 What's Inside

Each notebook has:
- A short description of the topic
- Easy examples with output
- Practice questions with solutions

## 🗺️ Roadmap

1. **Basics:** print, variables, input, data types, operators
2. **Control Flow:** if/else, loops
3. **Data Structures:** strings, lists, tuples, sets, dictionaries
4. **Functions & Modules**
5. **File & Error Handling**
6. **Object-Oriented Programming**
7. **Libraries & Projects:** NumPy, Pandas, mini projects

## 🚀 Getting Started

```bash
git clone https://github.com/<your-username>/python-learning-journey.git
cd python-learning-journey
pip install jupyter
jupyter notebook
```

You can also open any notebook in [Google Colab](https://colab.research.google.com/) with no setup.

## 💡 Tips

- Follow the notebooks in order
- Type the code yourself instead of copying
- Try the practice questions before checking solutions
